# Tutorials and Learning Resources

This section provides authoritative tutorials, documentation, guides, and learning resources for understanding AI-powered literature discovery, scholarly search, information retrieval, and research workflows.

## 1. Semantic Scholar — Product and Research Resources

**Provider:** Allen Institute for AI (AI2)

**Purpose:**
Semantic Scholar provides documentation and resources explaining how researchers can use AI-powered academic search to discover scientific papers, explore citations, and find related research.

**Why it is useful:**
This resource is useful for learning practical techniques for searching and navigating scholarly literature using an AI-powered academic search platform.

**Resource:**
[Semantic Scholar](https://www.semanticscholar.org/)

**API Documentation:**
[Semantic Scholar API](https://www.semanticscholar.org/product/api)

---

## 2. Elicit — Research Guide

**Provider:** Elicit

**Purpose:**
Elicit provides guides and documentation for using AI to search academic literature, analyze papers, extract information, and organize evidence for research.

**Why it is useful:**
It provides practical guidance for researchers learning how AI can support literature reviews and evidence synthesis.

**Resource:**
[Elicit](https://elicit.com/)

---

## 3. Google NotebookLM Help Center

**Provider:** Google

**Purpose:**
The official NotebookLM documentation explains how to create notebooks, add research sources, ask questions about those sources, and generate AI-assisted summaries and other research outputs.

**Why it is useful:**
It is useful for learning how to use a source-grounded AI system to analyze and connect information from research papers and other documents.

**Resource:**
[NotebookLM Help Center](https://support.google.com/notebooklm/)

---

## 4. Pyserini Documentation

**Provider:** Castorini Research Group

**Purpose:**
Pyserini documentation provides tutorials and technical guidance for conducting information-retrieval experiments using sparse and dense retrieval methods.

**Why it is useful:**
It helps researchers understand the technical foundations behind search and retrieval systems that can be applied to scholarly literature collections.

**Resource:**
[Pyserini Documentation](https://castorini.github.io/pyserini/)

**GitHub:**
[Pyserini GitHub Repository](https://github.com/castorini/pyserini)

---

## 5. Stanford Information Retrieval Book

**Provider:** Stanford University

**Purpose:**
*Introduction to Information Retrieval* is a comprehensive online textbook covering the foundations of information retrieval, including document indexing, retrieval models, ranking, evaluation, text classification, and web search.

**Why it is useful:**
The material provides the theoretical foundation needed to understand how search engines and literature-discovery systems retrieve and rank relevant documents.

**Resource:**
[Introduction to Information Retrieval](https://nlp.stanford.edu/IR-book/)

## Summary

These learning resources provide both practical and theoretical perspectives on AI-powered literature discovery. Semantic Scholar and Elicit demonstrate practical scholarly-search workflows, while NotebookLM provides a source-grounded approach to research analysis. Pyserini introduces practical information-retrieval experimentation, and the Stanford Information Retrieval textbook provides the theoretical foundations behind document search and ranking.

Together, these resources can help researchers understand both the practical use and technical foundations of modern literature-discovery systems.
